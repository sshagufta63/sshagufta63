### Key Learnings

* An API is the communication interface between an application and an AI model.
* A model processes input as tokens rather than complete sentences or paragraphs.
* Training is the process of learning patterns from data, while inference is the process of generating responses using a trained model.
* The context window limits how much information the model can consider at one time.
