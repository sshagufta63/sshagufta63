## Key Learnings

* AI is a broad field that includes Machine Learning.
* Machine Learning is a subset of AI.
* Deep Learning is a subset of Machine Learning.
* Large Language Models are Deep Learning models trained on vast amounts of text.
* LLMs generate responses by predicting the next token based on learned patterns.

---

## Question of the Day

### Why will an LLM trained on programming languages and technical documentation perform better than one trained only on books?

### My Understanding

An LLM trained on programming languages, documentation, GitHub repositories and technical material has learned patterns specific to software engineering. Because it has seen relationships between programming concepts, APIs, SQL, Java and Kubernetes, it can generate responses that are much more relevant to engineering problems.

The model has not simply memorized code. Instead, it has learned language and programming patterns that allow it to generate solutions for new problems.

---

## Reflection

### What surprised me?

LLMs are prediction engines that generate responses using learned patterns rather than storing ready-made answers.

### What confused me?

Understanding exactly how an LLM "learns" patterns instead of memorizing information. I expect this will become clearer as the course progresses.

### How can I apply this at work?

AI can assist with SQL explanations, code generation and technical reasoning because it has learned patterns from programming languages and technical documentation.
